LoRa Transmit Energy

Sensor reports are sent from node_send_sensor_report() in lora_driver.c as a fixed 19-byte binary packet (opcode 0x21). LoRa PHY settings: SF7, 125 kHz BW, CR 4/5, 8-symbol preamble, explicit header, CRC on, 14 dBm TX power. Time-on-air computed with the same formula as RadioTimeOnAir() in lora/radio/sx126x/radio.c.

Power Optimization Flowchart

Optimized path: kick off STCC4 CO₂ first (~510 ms conversion), read SHT40 / SGP30 / BH1620 in parallel (~70 ms total), STOP3 while CO₂ finishes, then apply an N-read filter — arithmetic mean of the last N raw readings per channel (N typically 3–5, default 5). Filtering uses prior report-cycle samples only; no extra sensor reads or energy. NODE_STOP3_ENABLE is currently 0 in lora_driver.c.

N-Read Filter (typically 3–5 samples)

Each report cycle stores one raw reading per channel in a ring buffer of depth N. The value sent over LoRa is the arithmetic mean of the last N readings. N = 3 responds faster; N = 5 (default) smooths more. Configurable in firmware — zero additional sensor energy. 
flowchart TD
    A([Report cycle — raw sensor reads complete]) --> B[For each channel:
T · RH · TVOC · lux · CO₂]

    B --> C["Ring buffer per channel
buf[0..N-1]  ·  N = filter depth"]

    C --> D["buf[k] = raw reading
k = sample_index mod N"]

    D --> E[sample_index++
wrap at N]

    E --> F{samples stored >= N?}

    F -->|No — warming up| G[Use partial mean over stored count
or defer TX until N reached]
    F -->|Yes| H["filtered = (buf[0] + … + buf[N-1]) / N
arithmetic mean per channel"]

    G --> I[Copy filtered values to report struct]
    H --> I

    I --> J{LoRa report due?}
    J -->|Yes| K[Pack 19-byte payload
filtered T · RH · TVOC · lux · CO₂]
    J -->|No| L([Wait next sample cycle])
    K --> M[LoRa TX]
    M --> L

Indoor Solar Sizing (5 min report interval)

Budget assumes a 40 mm × 40 mm (16 cm²) high-efficiency indoor amorphous panel (Amorton / optimized a-Si class), STCC4 single-shot + sleep CO₂ (required at this interval), MCU STOP3 between reports, BQ25505 harvester (~75% end-to-end), and 0.22 F supercap for TX bursts. Continuous CO₂ (~970 µA average) needs ~3.2 mW and is not viable on indoor PV this size.
