Sensor report sequence (target — tasks FW-010 through FW-014)

1. RTC wake from STOP3 → 2. Radio sleep → 3. STCC4 single-shot start (~510 ms) → 4. SHT40 + SGP30 + BH1620 in parallel → 5. STOP3 until CO₂ ready → 6. STCC4 read + sleep → 7. Push to N-sample buffers → 8. Compute mean → 9. Pack filtered 19-byte payload → 10. LoRa TX if vcap OK → 11. Rails off → STOP3.
